# Skill: generate-interview-questions

## 목적

완성된 자소서와 경험 DB를 바탕으로
예상 면접 질문과 각 질문에 대한 추천 답변 포인트를 자동 생성한다

## 트리거

"[이름] [기업명] 면접 질문 뽑아줘"

기업명 없이 "[이름] 면접 질문 뽑아줘" 입력 시 → 작성된 자소서 파일 목록을 보여주고 어떤 기업 자소서 기준으로 생성할지 선택하게 한다

## 실행 순서

### 1. 데이터 로드

아래 파일을 순서대로 읽는다.

- `outputs/[이름]/[기업명]_*.md` — 해당 기업에 작성된 자소서 전체
- `users/[이름]/experiences/` — 자소서에서 참조한 경험 파일 (참조한 경험명으로 특정)
- `users/[이름]/profile.md` — 인적사항·가치관
- `outputs/[이름]/[기업명]_culture.md` — 기업 컬쳐핏 메모 (있으면)

자소서 파일이 없으면:
> "[기업명] 자소서 파일이 없습니다. 먼저 자소서를 작성해 주세요."
출력 후 중단.

### 2. 질문 생성

아래 3가지 유형의 질문을 생성한다.

#### A. 자소서 기반 꼬리질문

자소서 각 문항에서 면접관이 파고들 만한 부분을 찾아 질문을 만든다.

추출 기준:
- 구체성이 부족해 보이는 부분 ("어떻게 했는지 더 설명해보세요")
- 수치나 결과가 궁금한 부분 ("실제로 얼마나 개선됐나요?")
- 본인의 기여와 팀의 기여가 불분명한 부분 ("그 중 본인이 직접 한 것은 무엇인가요?")
- 지원 직무와의 연결이 궁금한 부분 ("그 경험이 이 직무에서 어떻게 쓰일 것 같나요?")

#### B. 경험 기반 STAR 심층 질문

참조한 경험 파일의 STAR 구조에서 추가로 파고들 수 있는 질문을 만든다.

- Situation: 당시 상황을 더 구체적으로 묻는 질문
- Action: 선택지가 있었을 때 왜 그 방법을 택했는지 묻는 질문
- Result: 결과가 기대에 못 미쳤다면 어떻게 했는지 묻는 질문
- 이후: 그 경험 이후 달라진 점을 묻는 질문

#### C. 직무·가치관 역량 질문

profile.md 와 관심직무.md의 직무 핵심 키워드를 기반으로 역량 검증 질문을 만든다.

예:
- "~한 상황에서 어떻게 대처하시겠어요?" (상황 대처형)
- "본인의 ~에 대해 구체적인 사례로 말씀해주세요." (역량 확인형)
- "입사 후 첫 6개월 동안 어떤 목표를 세우시겠어요?" (포부형)

컬쳐핏 메모가 있으면 기업의 가치관과 연계된 질문을 1~2개 추가한다.

### 3. 출력 형식

```text
# [기업명] 면접 예상 질문

## A. 자소서 꼬리질문

### [자소서 문항 요약]
Q1. [질문]
→ 추천 포인트: [어떤 내용을 강조하면 좋은지 1~2줄]

Q2. [질문]
→ 추천 포인트: [어떤 내용을 강조하면 좋은지 1~2줄]

---

## B. 경험 심층 질문 ([경험명] 기반)

Q1. [질문]
→ 추천 포인트: [STAR 중 어느 부분을 보완해서 답하면 좋은지]

---

## C. 직무·가치관 역량 질문

Q1. [질문]
→ 추천 포인트: [어떤 경험 또는 가치관으로 연결하면 좋은지]

---
생성 기준: [기업명] 자소서 ([파일명]) + 경험 [N]개
```

### 4. output 저장

생성된 질문 목록을 `outputs/[이름]/[기업명]_면접질문.md`로 저장한다.
같은 파일이 이미 있으면 날짜 구분선을 추가하고 하단에 append한다.

## 절대 금지

- 자소서에 없는 내용을 기반으로 질문을 지어내지 말 것
- 추천 포인트에 경험을 새로 만들어 넣지 말 것
- 질문을 과도하게 많이 생성하지 말 것 (유형별 최대 5개, 총 15개 이내)
