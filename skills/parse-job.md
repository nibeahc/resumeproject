# Skill: parse-job

## 목적

사용자가 붙여넣은 채용공고 원문을 구조화된 공고 파일(`jobs/[출처]-[ID].md`)로 변환한다.
특히 필수조건과 우대조건을 **배열로 분리 추출**한다 — 통짜 텍스트로 두면 S5 매칭 엔진이
조건 단위로 비교할 수 없다.

## 트리거

"공고 등록해줘: [본문]" 또는 "이 공고 파싱해줘" (본문 붙여넣기와 함께)

## 절대 원칙

1. **이 스킬은 주어진 본문만 파싱한다.** 본문을 어디서 가져왔든(붙여넣기, URL 수집,
   파일 업로드) 이 스킬이 하는 일은 그 텍스트를 구조화하는 것뿐이고, 스스로 페이지를 열지
   않는다. 본문 없이 URL만 주어지면 본문을 붙여넣어달라고 요청한다.
   (수집은 `lib/jobsource.py` 가 `Claude.md` "외부 자료 수집 정책" 에 따라 처리한다.
   웹에서는 `/jobs` 화면의 "본문 가져오기" 와 "파일에서 읽기" 가 그 경로다.)
2. **원문에 없는 조건을 지어내지 않는다.** 모든 조건은 원문 문장에서 실제로 추출한 것이어야
   한다. 원문에 없는 자격요건, 수치, 마감일을 채워 넣지 않는다. 알 수 없는 항목은 빈 값으로
   둔다 (메타 필드는 `null`, 목록 필드는 `[]`).
3. **필수조건과 우대조건을 반드시 배열로 분리한다.** 한 줄에 조건 하나. 통짜 문장 하나에 조건이
   여러 개 들어 있으면 쪼갠다 (예: "컴퓨터공학 전공자 우대, 관련 자격증 소지자 우대" → 우대조건
   두 개).
4. **회사명/직무명을 원문에서 찾을 수 없으면 지어내지 않는다.** 이 경우 확인을 요청하거나
   (대화형), 코드 호출 시에는 호출자가 넘긴 힌트(company_hint/position_hint)로 채운다.

## 실행 순서

### 1. 메타 정보 추출

원문에서 아래를 찾는다. 없으면 빈 값(`null` 또는 `""`)으로 둔다.

- 회사명, 직무명
- 마감일 (원문에 날짜가 명시된 경우만. "채용 시 마감"/"수시채용" 등은 상시채용으로 표기)
- 고용형태 (정규직/인턴/계약직/체험형)
- 근무지, 경력 조건 (신입/경력 N년/무관)

**공고 ID와 수집일은 채우지 않아도 된다.** 공고 ID는 실행 시점에 코드가 순번을 매겨서
정하고, 수집일은 코드가 오늘 날짜로 채운다 — 모델은 오늘이 며칠인지 알 방법이 없으므로
이 두 필드를 추측해서 채우면 실제 값과 어긋난다(실측으로 확인: 실행마다 서로 다른 날짜를
지어냄). JOB_MARKDOWN 의 이 두 줄은 템플릿 예시 그대로 두거나 비워두면 된다.

### 2. 필수조건과 우대조건 분리 추출

원문에서 "자격요건"/"지원자격"/"필수"로 표시된 부분은 필수조건으로,
"우대사항"/"우대"로 표시된 부분은 우대조건으로 배열에 담는다.

원문에 이 구분이 아예 없으면 문맥으로 판단하되, 판단이 애매하면 **필수조건 쪽에 넣는다**
(우대를 필수로 잘못 넣는 것보다, 필수조건을 우대로 잘못 빼서 매칭 점수가 실제보다 후하게
나오는 쪽이 더 위험하다).

각 조건은 원문 표현을 그대로 옮기되, 한 줄에 요구사항 하나만 담는다.

### 3. 자기소개서 문항

원문에 자소서 문항이 명시되어 있으면 문항과 글자수를 표로 뽑는다. 명시되어 있지 않으면
표를 비워둔다 (지어내지 않는다).

### 4. 주요업무 / 인재상

주요업무는 원문을 3~5줄로 요약한다. 인재상/키워드는 원문에서 반복 등장하는 표현 중심으로
뽑는다 — 배경지식으로 임의 추가하지 않는다.

### 5. 출력

아래 네 블록을 이 순서 그대로, 정확히 이 형식으로만 출력한다. 다른 설명은 블록 밖에 쓰지 않는다.

```text
===JOB_MARKDOWN===
(templates/job-entry.md 의 섹션 구성을 그대로 따른다: 메타 / 필수조건 / 우대조건 /
자기소개서 문항 / 주요업무 / 인재상·키워드 / 원문. "매칭 결과" 섹션은 비워둔다 —
그 섹션은 skills/match-jobs.md 전용이다. "원문" 섹션에는 입력받은 본문 전문을 그대로 담는다)
===END===

===REQUIRED_JSON===
["조건 1", "조건 2"]
===END===

===PREFERRED_JSON===
["조건 1"]
===END===

===META_JSON===
{"company": "회사명", "position": "직무명", "deadline": "YYYY-MM-DD 또는 null",
 "employment_type": "정규직/인턴/계약직/체험형 또는 null", "career": "신입/경력 N년/무관 또는 null",
 "location": "근무지 또는 null"}
===END===
```

REQUIRED_JSON/PREFERRED_JSON/META_JSON 은 JOB_MARKDOWN 안의 체크박스·메타와 내용이 반드시
일치해야 한다 (같은 정보를 두 형태로 중복 출력하는 것 — 코드가 매칭·DB 저장에는 JSON 블록만
쓰고, 사람은 JOB_MARKDOWN 만 읽는다).

## 절대 금지

- 이 스킬 안에서 채용 사이트를 직접 열어 본문을 가져오는 것
- 원문에 없는 조건, 수치, 마감일을 지어내는 것
- 필수조건과 우대조건을 하나의 배열로 합치는 것
- 원문에 명시되지 않았는데 "상시채용"으로 단정하는 것
- 회사명/직무명을 추측으로 지어내는 것
