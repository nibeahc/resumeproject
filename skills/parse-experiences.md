# Skill: parse-experiences

## 목적
users/[이름]/raw/ 안의 자소서 원본 파일을 읽고
구조화된 경험 파일과 어투 분석 파일을 자동 생성한다

## 트리거
"[이름] 파싱해줘" 또는 "[이름] 자소서 정리해줘"

## 실행 순서

### 1. raw/ 파일 읽기
- users/[이름]/raw/ 안의 모든 파일을 읽는다
- 파일이 없으면 "raw/ 폴더에 자소서 파일이 없습니다" 출력 후 중단

### 2. writing-style.md 생성
raw/ 전체를 읽고 아래 항목을 분석해서
users/[이름]/writing-style.md 를 생성한다

- 문장 길이 경향 (짧고 간결 / 길고 서술적)
- 자주 쓰는 문장 시작 방식
- 자주 쓰는 어미 (예: ~했습니다 / ~했어요 / ~했다)
- 자주 쓰는 표현이나 단어
- 전반적인 톤 (감성적 / 논리적 / 경험 중심 등)
- 특징적인 문체 습관

### 3. 경험 목록 추출 (중복 처리 포함)
raw/ 전체에서 등장하는 모든 경험을 먼저 목록으로 추출한다

#### 중복 판단 기준
아래 중 2개 이상 겹치면 같은 경험으로 판단한다
- 활동명 또는 기관명이 동일하거나 유사
- 시기가 겹침
- 핵심 에피소드(사건)가 동일

#### 중복 처리 방법
같은 경험으로 판단된 경우
- 파일은 하나만 생성한다
- 여러 자소서에 걸쳐 나온 표현 중 가장 구체적이고 풍부한 내용을 선택한다
- STAR 각 항목별로 가장 잘 서술된 버전을 골라 합친다
- "이 경험으로 쓸 수 있는 문항 유형" 은 모든 버전에서 나온 것을 합산한다

#### 중복 판단이 애매한 경우
- 일단 별도 파일로 생성한다
- 파일 하단에 "⚠️ 확인 필요: [파일명]과 유사한 경험일 수 있음" 을 표시한다

### 4. 경험 파일 생성
추출된 경험을 templates/experience-entry.md 형식에 맞춰
users/[이름]/experiences/ 안에 파일로 저장한다

파일명 규칙:
- [시기시작연도]-[활동명요약].md
- 예: 2021-창업동아리팀장.md, 2022-카카오인턴.md

시기를 알 수 없는 경우:
- 본문에서 추론 시도 (대학교 n학년, n년 전 등)
- 추론 불가 시 파일명을 0000-[활동명].md 로 저장하고
  메타의 시기 항목에 "확인 필요" 로 표시

### 5. index.md 생성
추출된 모든 경험을 바탕으로
users/[이름]/index.md 를 생성한다

형식:
## 카테고리별
- 리더십: [경험명], [경험명]
- 팀워크: [경험명], [경험명]
- 문제해결: [경험명]
- 성장·실패: [경험명]
- 전문성·직무역량: [경험명]
- 가치관·동기: [경험명]

## 키워드별
- 갈등조율: [경험명]
- 데이터분석: [경험명]
- ...

### 6. 완료 보고
아래 형식으로 결과를 출력한다

---
파싱 완료: [이름]
- writing-style.md 생성 완료
- 경험 파일 [N]개 생성
  - [파일명 목록]
- 중복 처리: [N]건 → 하나로 합침
  - [합쳐진 경험 목록]
- 확인 필요 항목:
  - 시기 불명확: [경험 목록]
  - 중복 애매: [경험 목록]
- index.md 생성 완료
---

## 절대 금지
- raw/ 파일을 수정하거나 삭제하지 말 것
- 경험을 지어내거나 과장하지 말 것
- 판단이 애매한 경험을 임의로 합치지 말 것
- 하나의 경험을 여러 파일로 중복 저장하지 말 것
