# 자소서 작성 트렌드 저장소

```text
raw/YYYY-MM-DD.md   수집 결과. lib/trends.py 의 자동 갱신이 여기에만 쓴다
approved.md         사람이 검토해 승인한 내용. 자소서 생성 프롬프트에 들어가는 유일한 파일
history/            이전 승인본 (되돌릴 수 있게)
```

## 왜 나눴나 (S11-6, 설계검토 F-1)

예전엔 `coverletter-trends.md` 한 파일이었고 한 달에 한 번 자동으로 **덮어써졌다.**
그 파일이 그대로 생성 프롬프트에 들어갔으므로, 아무도 읽지 않은 검색 결과가 다음 달부터
작성 정책이 되는 구조였다.

이제 자동 갱신은 `raw/` 에만 쓴다. `approved.md` 는 사람이 `/trends` 화면에서 올린다.
**자동 갱신이 승인본을 건드리지 못한다**는 것이 이 구조의 전부다.

## 검토할 때 보는 것

- 각 주장에 출처 URL 과 발행일이 있는가. 없으면 자소서 근거로 쓰지 않는다
- 커뮤니티 감상(문장부호 취향 등)을 공식 채용 기준처럼 쓰고 있지 않은가
- "수치를 반드시 포함하라" 같은 강한 권고는 "근거 있고 논지에 필요한 수치만 포함하라"
  정도로 낮춘다. AI 탐지 점수나 쉼표 개수는 품질 목표가 아니다
- `writing-rules.md` / `writing-style.md` 와 충돌하는 항목은 빼거나 조건을 붙인다.
  충돌 시 우선순위는 `Claude.md` "규칙 우선순위" 가 정한다 (트렌드가 가장 아래다)
