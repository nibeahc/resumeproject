# 자소서 자동 작성 시스템

자소서 원본 파일을 구조화된 경험 DB로 파싱하고, 사용자의 어투로 자소서를 자동 작성하는 AI 에이전트 시스템입니다.

## 시작하기 (새 유저 추가)

### 1. 폴더 만들기

```
users/[이름]/
  raw/
    apply/    ← 자소서, 지원서, 신청서, 포트폴리오 등
    logs/     ← 소감문, 활동일지, 결과보고서 등 (선택)
```

### 2. 원본 파일 넣기

`raw/apply/` 폴더에 자소서·지원서 파일을 넣습니다.
지원 형식: `.hwpx`, `.hwp`, `.docx`, `.pdf`, `.md`, `.txt`

### 3. 파싱 실행

Claude에게 아래 명령어를 입력합니다:

```
[이름] 파싱해줘
```

자동으로 생성되는 파일:

- `users/[이름]/experiences/` — 경험 DB (경험별 개별 파일)
- `users/[이름]/writing-style.md` — 어투·문체 분석
- `users/[이름]/profile.md` — 인적사항·가치관 (수동 작성 권장)
- `users/[이름]/index.md` — 경험 키워드·카테고리 색인
- `users/[이름]/관심직무.md` — 희망 직무 및 직무별 핵심 키워드

## 명령어

| 명령어 | 설명 |
|--------|------|
| `[이름] 파싱해줘` | raw/ 파일 → 경험 DB 자동 생성 |
| `[이름] 이력 보여줘` | 전체 경험 목록 조회 (카테고리별 표) |
| `[이름] 이력 타임라인 보여줘` | 전체 경험 조회 (연도별 타임라인) |
| `[이름] [키워드] 관련 이력 보여줘` | 키워드 필터 조회 |
| `[이름] [직무명] 직무로 이력 보여줘` | 직무 관련도 순 조회 |
| `[이름] 자소서 써줘: [문항] / [글자수]` | 자소서 문단 작성 |

## 폴더 구조

```
ResumeProject/
  users/[이름]/
    raw/
      apply/          ← 원본 지원 서류 (건드리지 않음)
      logs/           ← 원본 활동 기록 (건드리지 않음)
    experiences/      ← 파싱 결과 경험 DB
    profile.md
    writing-style.md
    index.md
    관심직무.md
  skills/             ← 에이전트 작업 절차
  templates/          ← 데이터 표준 포맷
  outputs/[이름]/     ← 작성된 자소서 결과물
  record/             ← 세션 히스토리 아카이브
```

## 개인정보 보호 (.gitignore)

`users/` 폴더 안의 개인 데이터를 Git에 올리지 않으려면 `.gitignore`에 아래를 추가하세요:

```
users/
outputs/
```

## 주의사항

- `raw/` 폴더의 원본 파일은 절대 수정·삭제하지 않습니다
- 경험은 지어내거나 과장하지 않습니다
- 자소서 작성 시 글자수 제한이 없으면 먼저 물어봅니다
